# Market Lab

Claude Code workspace for market analysis and trade ideas: data layer with caching (Yahoo, Stooq, FRED, SEC, crypto,
CFTC, news/social, IG read-only), full TA catalogue with signal hit rates, options, earnings reactions, sentiment,
macro and fundamentals desks, Soros/Buffett/Burry lens playbooks, trade cards and a trade journal, plus a quant
research layer: 21 algorithmic strategies in backtest, signal and paper modes, validation (OOS, PSR/DSR, bootstrap,
permutation) and pre-registered hypothesis testing.

```bash
bash bootstrap.sh     # then ./mlab --help
```

Start with `CLAUDE.md`, then the wiki in `docs/wiki/Home.md`. Network/secrets: `docs/NETWORK.md`. Skills map: `docs/SKILLS_MAP.md`.
