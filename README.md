# Market Lab

Claude Code workspace for market analysis and trade ideas: data layer with caching (Yahoo, Stooq, FRED, SEC, crypto,
CFTC, news/social, IG read-only), full TA catalogue with signal hit rates, options, earnings reactions, sentiment,
macro and fundamentals desks, Soros/Buffett/Burry lens playbooks, trade cards and a trade journal.

```bash
bash bootstrap.sh     # then ./mlab --help
```

Start with `CLAUDE.md`. Network/secrets: `docs/NETWORK.md`. Skills map: `docs/SKILLS_MAP.md`.
