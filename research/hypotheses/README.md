# Hypotheses

One file per pre-registered hypothesis, `H-<yyyymmdd>-<slug>.md`, created by `bash mlab hypo new` on a
`hypo/<yyyymmdd>-<slug>` branch and graded once by `bash mlab hypo test`. PASS and FAIL both merge to main:
the failures are the trial count behind every deflated Sharpe. See `docs/wiki/Hypothesis-Testing.md`.
